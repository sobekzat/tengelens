# TengeLens — анализ банковских выписок с ML

Загружаете выписку Kaspi Gold (PDF) или CSV любого банка → за секунды получаете:

- **ML-категоризацию** расходов (TF-IDF по символьным n-граммам + Logistic Regression, 18 категорий, мерчанты Казахстана; устойчиво к опечаткам и транслиту);
- **поиск подписок** и регулярных платежей (интервал 25–35 дней, стабильная сумма) с суммой в год;
- **поиск аномальных трат** (робастный z-score по MAD относительно мерчанта/категории);
- **прогноз расходов** на следующий месяц по категориям;
- **персональные инсайты**: рост категорий, «эффект латте», норма сбережений, доставка vs продукты.

Файл обрабатывается только в памяти и нигде не сохраняется.

## Запуск

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
# открыть http://localhost:8000 → «Посмотреть на демо-данных»
pytest -q   # 6 тестов
```

## Стек
Python · FastAPI · pandas · scikit-learn · pdfplumber · Chart.js · pytest

## API
| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/analyze` | multipart `file` (.pdf Kaspi / .csv) → JSON-отчёт |
| GET | `/api/demo` | отчёт по демо-выписке |
| GET | `/docs` | Swagger |

## Модель монетизации
| Тариф | Цена | Что входит |
|---|---|---|
| Free | 0 ₸ | 1 выписка/мес, базовый отчёт |
| Pro | 990 ₸/мес | история за год, лимиты и уведомления в Telegram, PDF-отчёт о доходах/расходах (для ипотеки, визы) |
| B2B / White-label | от 150 000 ₸/мес | API для финансовых консультантов, бухгалтеров, MFO-скоринга (с согласия клиента) |

Каналы: TikTok/Instagram Reels «разбор моих трат за месяц», Telegram-каналы о финграмотности, студенческие чаты.
Приём платежей: Kaspi Pay / Freedom Pay / Telegram Stars.
